# IRIX COST — версия для ККЗМ

Файл: `IRIX-COST-ккзм.html` — открывается прямо в браузере, установка не нужна.

## Что это

Приложение для расчёта себестоимости и калькуляции на основе трёх выгрузок из 1С:
- спецификации (состав изделий),
- закупочные цены,
- продажи.

Все данные загружаются через интерфейс приложения (три зоны загрузки) и после этого остаются в кэше браузера (localStorage) — при следующем открытии файла подгружать заново не нужно.

## Что было не так и что поправлено

Выгрузка спецификаций у ККЗМ («мпецификации-ккзм.xlsx») устроена немного иначе, чем у предыдущих контрагентов: в 1C техническая колонка «Спецификация.Состав.Номенклатура» (имя компонента) стоит в той же колонке, что и «Номенклатура» самого изделия — колонка переиспользуется.

Старый код различал строку-изделие и строку-компонент по номеру колонки, а раз колонки совпали — вообще не находил строк-изделий. Спецификации грузились пустыми (0 позиций, 0 компонентов), хотя приложение никакой ошибки не показывало.

Добавлена отдельная ветка разбора: когда колонка имени совпадает с колонкой изделия, тип строки определяется по содержимому колонки количества (у компонента там число, у изделия — текст вида «Спецификация …»). Заодно убран смежный баг: если в файле нет колонки характеристики компонента, туда раньше по ошибке попадало значение из соседней колонки.

Проверено на ваших файлах:

| Файл | Результат |
|---|---|
| Спецификации | 398 изделий, 1108 компонентов (было 0/0) |
| Закупочные цены | 583 позиции — тут проблем не было |
| Продажи | 79 позиций — тоже без проблем |

## На что обратить внимание

Из 135 уникальных материалов, встречающихся в спецификациях, цена нашлась только для 55. Остальное — в основном листовой и трубный прокат — просто не входит в переданную выгрузку закупок (видимо, закупается отдельным каналом). Это не баг приложения, а особенность данных: по этим позициям расчёт покажет цену «none», пока не появится источник цены (закупка, остатки или вручную через справочник цен).

## Как пользоваться

1. Откройте `IRIX-COST-ккзм.html` в браузере.
2. Загрузите по очереди три файла в соответствующие зоны: спецификации, закупочные цены, продажи.
3. Приложение само посчитает калькуляцию и сохранит загруженные данные в кэше браузера — при повторном открытии этого же файла в этом же браузере данные подхватятся автоматически.

## Если формат выгрузки снова изменится

Если у следующего контрагента спецификации опять не распознаются (счётчик показывает 0 позиций / 0 компонентов при непустом файле) — это тот же класс проблемы: 1C может по-разному раскладывать колонки в зависимости от настроек отчёта. Пришлите файл — поправим разбор под конкретную раскладку так же, как в этот раз.
